# Neural model

`weights.bin` (~15 MB) + `weights.json` are the pretrained Graves
handwriting-synthesis weights the neural engine loads.

Source: `sjvasquez/handwriting-synthesis` (calligrapher.ai), Alex Graves' model
trained on the IAM On-Line Handwriting Database. Published here with permission.

Regenerate with `extract_weights.py` from the upstream `checkpoints/model-17900`.
